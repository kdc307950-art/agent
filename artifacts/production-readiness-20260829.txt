一、实现内容（对照收尾方案 9 阶段）
----------------------------------------------------------------------
阶段一  权限模型收敛（部门身份透传）
  - RunContext 增加 role / departments / internal（默认值向后兼容）
  - backend/knowledge/identity.py：retrieval_principal(context) 统一封装，
    替换 4 处手工构造（copilot tools / helpdesk tools / copilot service /
    intake graph 注释说明 SYSTEM 场景）
  - copilot/api.py：_lookup_agent_departments 从 support_members JOIN
    support_teams 服务端查询坐席部门（不信任请求体）
  - ACL 集成测试（test_identity_acl_postgres.py）：跨租户/restricted 部门
    隔离/IT 与财务互不可见/过期文档不能作引用/伪造部门不改变权限

阶段二  Copilot 真正异步 Worker 化（生产化前最重要架构缺口）
  - copilot_runs 状态扩展 queued/processing/completed/failed/dead/expired
    + worker 字段（worker_id/next_attempt_at/claimed_at，schema v19）
  - POST /tickets/{id}/copilot：只校验 + 创建 queued 运行，立即返回 202
    （Web 进程不执行模型调用）
  - CopilotWorker（backend/copilot/worker.py）：FOR UPDATE SKIP LOCKED 领取、
    租约 + 心跳续租、指数退避重试、超过重试次数 -> dead、
    recover_orphaned_runs 崩溃恢复（回队）
  - run_copilot_worker.py 独立进程入口（SIGINT/SIGTERM 优雅停止）
  - GET /tickets/{id}/copilot/{run_id}：运行状态轮询接口（前端轮询目标）
  - 前端 CopilotPanel：POST 202 -> 轮询 run 状态 -> completed 展示草稿 /
    failed 可重试 / dead 转人工；切换工单取消轮询
  - 测试：test_copilot_worker.py（完成/退避/dead/崩溃恢复）、
    test_copilot_api.py 适配异步语义

阶段三  统一知识检索入口
  - backend/knowledge/retriever.py：KnowledgeRetriever.search()
    （lexical + vector + RRF 融合 + ACL/有效期过滤）
  - retrieval_mode 显式标记：lexical-only / hybrid（两套评测分开记录）
  - HttpEmbeddingProvider 增加 embed_documents：批量 texts 请求、单批 ≤32 条、
    复用单一 AsyncClient、任一向量异常直接失败
  - 测试：test_knowledge_retriever.py（lexical-only/hybrid/降级/模式标记）

阶段四  工具治理完善
  - 结构化 error_code（阶段四）：ToolInvocationResult 增加 error_code，
    _classify_governance_error 映射 ToolGovernance 固定文案
    （denied_scope/denied_tenant/denied_unregistered/denied_input/timeout/failed），
    不再靠错误文本判断状态；tool_trace 记录 error_code
  - get_ticket_messages / get_ticket_history 已最小字段 + ticket:agent scope

阶段五  恢复逻辑独立化 + 指标补全
  - 恢复由 CopilotWorker 定期执行（HTTP 请求不再承担 recover 职责）
  - Worker 指标：copilot_lease_recovered_total / copilot_completed_total /
    copilot_retried_total / copilot_dead_total / copilot_runs_total{status}
  - worker 心跳经 WorkerMetricsDB.safe_beat（/ready 判定存活）

阶段七  前端工作台
  - CopilotPanel 异步轮询：202 入队 -> 轮询 GET run 状态 -> completed/failed/dead
    状态完整；防重复点击、切换工单取消轮询、旧结果不覆盖新工单
  - copilotPollConfig 抽到独立文件（修复 Fast refresh 警告）

阶段九  面试文档
  - docs/interview/copilot-architecture.md（新增）
  - docs/interview/known-limitations.md（新增 13-15 条 Copilot 边界）
  - docs/interview/demo-script.md（10 分钟时间表加入 Copilot 环节）
